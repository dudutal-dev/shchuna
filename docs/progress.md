## M1 — מנוע ליבה
- [x] Scene (שכבות, גלילה אופקית, פתיחה מימין), Entity, גרירה עם snap, אינטראקציות (tap, toggle, useOn)
- [x] SaveManager (debounce, מיגרציות, עמידות לשמירה פגומה), UndoStack (20 צעדים לכל מקום)
- [x] `docs/style-guide.md`
- [x] סצנת בדיקה: 3 חפצים נגררים (תפוח, כדור, כוס), מנורה, שולחן, מדף, כיור

החלטות:
- **גובה עולם 600 יחידות**, כדי שאזור מגע של 104 יחידות יהיה לפחות 64 נקודות גם בטלפון.
- **שכבת ריהוט נפרדת**, כדי שתפוח על שולחן יצויר מול השולחן גם כשהרגליים של השולחן נמוכות ממנו.
- **בלי GSAP**: tween קטן משלנו, כפי ש-SPEC מאפשר. הוא גם מכבד `prefers-reduced-motion`.
- **בלי texture atlas בינתיים** (חריגה מ-SPEC §10.3): ה-SVG עוברים רסטריזציה בזמן טעינה. נחזור לזה ב-M8 אם המדידה ב-iPad תדרוש.
- **חפץ שנפל מעל משטח נוחת עליו** ולא על הרצפה. זו הרחבה טבעית של SPEC §5.2.
- `holdIn`, `sitOn` ו-`lieOn` מוגדרים בטיפוסים, והמימוש ב-M4 יחד עם הדמויות.

פתוח: לא נמדד 60fps על מכשיר אמיתי, רק ב-Chromium עם רינדור תוכנה.

## M2 — קול
- [x] `voice-lines.json`, `gen-voice.ts` (hash, `--only`, `--dry-run`, נרמול ל-16- LUFS, הגנה על המפתח)
- [x] `AudioManager` (ביטול קול קודם, גרסאות `.m`/`.f`, ducking למוזיקה), fallback ל-Web Speech ב-dev בלבד
- [x] `check-niqqud.ts` ו-`check-bundle.ts` רצים בכל `npm run build`
- [x] מסך פתיחה "גע כדי להתחיל", שמשחרר אודיו ב-iOS
- [ ] **ריצה אמיתית מול ElevenLabs והאזנה:** מחכה למפתח ולקולות של דודו

נבדק בלי לשלם, מול `fetch` מדומה שמחזיר MP3 אמיתי: יצירה, נרמול, דילוג בריצה שנייה, המשך אחרי כשל, הסתרת המפתח משגיאות, בנייה קשיחה וטעינת MP3 בדפדפן תחת ה-CSP. **לא נבדק עדיין:** ה-API האמיתי, איכות הקול בעברית, והאם המודל באמת מתחשב בניקוד.

החלטות:
- **מודל: `eleven_v4` עם `language_code: "he"`.** התיעוד מציין עברית ב-v4 וב-v3, ודגמי multilingual_v2 ו-flash לא מציינים אותה. אפשר להחליף דרך `ELEVENLABS_MODEL`. ‏$0.08 לכל 1,000 תווים.
- **אפקטים (הקשה, הרמה, הנחה) מסונתזים ב-Web Audio** ולא קבצים: אין מה לטעון, כך שהמשוב מיידי. שדרוג אפשרי ב-M8.
- **מוזיקה:** ה-API קיים, הקבצים יגיעו ב-M8.
- **`SHCHUNA_ALLOW_MISSING_VOICE`:** מאפשר בנייה בלי הקלטות. קיים ב-e2e (הבדיקות לא תלויות בקול בתשלום), וזמנית גם בפריסה. צריך להסיר אותו מ-`deploy.yml` כשההקלטות ייכנסו.
- **`proofread: false` ב-`voice-lines.json`** הוא המקביל ל-`// TODO: proofread`, כי ב-JSON אין הערות.
- **`Web Speech` נשאר ב-dev בלבד**, כי בדפדפן הוא עלול לפנות לרשת, בניגוד לכלל ברזל 2.
